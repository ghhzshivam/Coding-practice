Pointer = address of variable
Pointer stores address, *pointer accesses the value at that address

int a = 10;
int *p = &a;
Expression	Meaning
a	value
&a	address
p	address
*p	value at address
Your house = variable
Your house number = memory address
A paper that has your house number written on it = pointer
So:
Variable → holds data
Pointer → holds where the data lives
Pointer = address holder
* = go to that address
DS = memory + pointers
printf("%d", *p);   // 10
